# Dutch Day 2 – Greetings & Introduction 🇳🇱

Yeh ek **interactive HTML learning page** hai jo **Dutch (A1 level)** ke greetings aur introduction ke liye banaya gaya hai. Is mein Roman Urdu explanation bhi di gayi hai taake Urdu bolne wale learners aasani se samajh sakein.

---

## 📖 Features

### 1. 📚 Words (Vocabulary Tables)
Teen tables mein words diye gaye hain:

| Section | Content |
|---------|---------|
| **Greetings** | Hallo, Goedemorgen, Goedemiddag, Goedenavond, Tot ziens, Doei |
| **Shukriya & Politeness** | Dank je wel, Dank u wel, Alsjeblieft, Sorry |
| **Hal Pochna & Introduction** | Hoe gaat het?, Goed dank je, Ik heet..., Ik kom uit Pakistan, Aangenaam |

Har word ke saath:
- **Dutch** spelling
- **Pronunciation** (Roman)
- **English** meaning
- **Roman Urdu** meaning
- **Example** sentence
- **Kab use hota hai** (usage timing)
- **🔊 Speaker button** (Dutch voice sunne ke liye)

---

### 2. 🃏 Flashcards
- Card par pehle **Roman Urdu** dikhta hai
- Tap karne par **Dutch word + pronunciation + English + example** show hota hai
- **Pichla / Agla / Suniye** buttons se navigate karein

---

### 3. 🎯 Quiz
- 8 multiple-choice questions
- Sahi jawab par **green**, ghalat par **red** highlight
- Score ke saath feedback:
  - 7+ → "Shabash! 🌟"
  - 5–6 → "Achha hai, thodi aur practice 👍"
  - <5 → "Words dobara dekhein 💪"

---

### 4. 🧩 Sentence Builder
- Roman Urdu prompt diya jata hai (jaise "Subah ka salaam karein")
- Shuffled Dutch words ko sahi order mein lagana hota hai
- **Check** button se verify karein
- **Dobara** se reset, **Agla** se next sentence

---

## 🧠 Sentence Formulas

```
Ik + heet + [naam]        → Ik heet Sara.        (Mera naam Sara hai)
Ik + kom + uit + [mulk]   → Ik kom uit Pakistan. (Main Pakistan se hoon)
```

---

## 🌷 Culture Note

- **je** = informal (dost, family, bachche)
- **u** = formal (bade, ajnabi, office)
- Milte waqt **handshake** aam hai
- Kuch family/doston mein **3 baar gaal par kiss** (left-right-left) bhi hota hai — yeh har shakhs ka apna tareeqa hai
- Muskura kar **"Hallo"** kehna hamesha theek hai
